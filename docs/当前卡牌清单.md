# 当前卡牌清单

本文件记录当前 Demo 中玩家可获得卡牌。玩家选择职业后，奖励、事件和坊市从通用卡池与该职业卡池中取卡。

当前奖励、事件、宝箱和坊市会按编号卡包过滤。卡牌数据中预留并填充 `unlock_tier`、`unlock_pack`、`unlock_packs`、`default_unlocked`：现阶段仍兼容 0 / 1 / 2 层级，但实际包名已经整理为 `common_1`、`common_2`、`sword_1` 等编号卡包。代码中 `CARD_UNLOCK_PACKS` 是当前已实现卡牌的显式包表。角色准备页先显示通用 1-5 和当前职业 1-5 的卡包槽位；未开放槽位不会进入奖励池。起始牌组不受解锁过滤影响。

敌人不受玩家职业卡池限制。敌方卡组按敌方卡组模板写死或随机选择；模板再引用可出场角色，角色本身不反向绑定卡组。当前第一版只让敌人主动使用少量伤害、削弱和轻装备牌，暂不让敌方使用放置牌、盖伏响应牌和复杂检索牌。

战斗中只有我方和敌方两个阵营牌手。卡牌长期应使用“我方主单位”“敌方主单位”“选定单位”等阵营相对概念；文中仍写“玩家”的旧描述后续需要逐步迁移为“我方主单位”或“我方阵营”。

卡牌检索和字段解锁只看明确数据字段，例如 `tags`、`search_tags`、`unlock_pack` 和单位标签，不扫描卡面效果说明文本。

当前不做金木水火土等属性规则。类似“火”“雷”“金”等字只作为卡名或风味字段，不参与额外克制和加成。

默认伤害会被目标防御力减免。只有卡面明确写“无视防御”的效果才不受防御影响。

## 通用卡组扩展草案（待实现）

本节是后续扩充通用卡池的设计名单。第一批优先实现牌已经接入代码，其余候选继续作为后续筛选池。目标是让通用卡池成为所有职业都可使用的基础法术、道具、装备、召唤和放置区互动库；职业卡池则继续负责职业资源、职业终端和职业打法差异。

### 底层能力

- 放置牌：已接入。明牌进入放置区，占用 1 个放置区槽位，可带倒计时、触发次数或持续效果。
- 压牌：已接入。部分放置牌可把从卡组选择的卡压在自身下方。若放置牌被破坏，被压牌进入墓地。
- 倒计时：已接入。玩家回合开始时减少 1。倒计时为 0 时结算效果，然后按卡面说明进入墓地、除外区或继续留场。
- 状态计数器：已接入第一批。当前优先支持破甲、虚弱、灼伤、迟滞、下次减伤。

### 通用状态草案

| 状态 | 默认规则 | 设计目的 |
|---|---|---|
| 破甲 | 防御力临时下降对应层数。回合结算时层数 -1。 | 让低伤害牌、普攻和多段攻击更容易穿透。 |
| 虚弱 | 攻击力临时下降对应层数。回合结算时层数 -1。 | 给玩家前期生存和控压工具。 |
| 灼伤 | 回合结束时受到对应层数伤害，然后层数 -1。 | 做持续伤害入口，不依赖属性克制。 |
| 迟滞 | 下一次行动造成的攻击或施法伤害减少对应数值，然后移除。 | 做温和控制，先不做便宜眩晕。 |

眩晕、控制、沉默、夺取行动等强控制先不放入低分通用池。后续可作为高分牌、敌方机制或特定职业机制。
