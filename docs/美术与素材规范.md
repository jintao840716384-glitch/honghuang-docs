# 美术与素材规范

## 当前状态

当前项目主要使用 Godot 控件、颜色、边框、光晕和文字构成 Demo UI，尚未接入正式美术素材。

## 当前美术方向

- 战斗界面优先清晰，不追求复杂装饰。
- 卡牌颜色按类型区分。
- 法防、装备、响应、奖励等状态用光效和边框表达。
- 探索地图当前是功能型节点图，未来可以替换为更有修仙/洪荒氛围的地图视觉。

## 需要的素材类别

未来可能需要：

- 职业立绘或角色半身像。
- 敌人立绘。
- 卡牌底框。
- 卡牌插画。
- 地图节点图标。
- 地图背景。
- 战斗背景。
- 法术特效。
- 攻击、受击、破坏等特效。
- UI 图标。

## 当前占位规则

- 没定风格前，不急着制作大量正式素材。
- 可以先用简单色块和清晰轮廓表达功能。
- 只在交互已经稳定的地方逐步替换素材。

## 待定

- 最终视觉风格：偏国风水墨、玄幻厚涂、简洁符箓风，还是更游戏化的高对比风格。
- 卡牌是否需要统一版式模板。
- 敌人是否用静态立绘、Live2D 式层级动画，还是简单动态头像。
- 地图是否做成卷轴、山门路径、星图或秘境路线。
