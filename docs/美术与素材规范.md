# 美术与素材规范

## 当前状态

当前项目主要使用 Godot 控件、颜色、边框、光晕和文字构成 Demo UI，尚未接入正式美术素材。

## 当前原则

- 先保证信息清晰，再考虑装饰。
- 卡牌颜色按功能和类型区分。
- 法防、装备、响应、奖励等状态用光效和边框表达。
- 未稳定的界面不急着制作正式素材。

## 后续素材类别

- 职业立绘或角色半身像。
- 敌人立绘。
- 卡牌底框。
- 卡牌插画。
- 地图节点图标。
- 地图背景。
- 战斗背景。
- 法术特效。
- 攻击、受击、破坏等反馈特效。
- UI 图标。

## 待定方向

- 最终视觉风格。
- 卡牌版式模板。
- 敌人表现方式。
- 探索地图视觉形式。
