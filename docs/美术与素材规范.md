# 美术与素材规范

## 当前状态

当前项目主要使用 Godot 控件、颜色、边框、光晕和文字构成 Demo UI，尚未接入正式美术素材。

## 当前原则

- 先保证信息清晰，再考虑装饰。
- 卡牌颜色按功能和类型区分。
- 法防、装备、响应、奖励等状态用光效和边框表达。
- 未稳定的界面不急着制作正式素材。
- 视觉素材路径、分类和占位色登记到 `VisualAssetDatabase.gd`；角色头像 / 战斗精灵由 `CharacterVisualDatabase.gd` 解释。
- 正式导入素材必须登记到 `AssetAttributionDatabase.gd`，记录来源、作者、授权、是否可商用和备注。
- 授权不清楚的素材只能作为本地临时参考，不进入正式资源库，不作为 Steam 商用构建资产。
- UI、战斗规则、角色数值和卡牌数据不直接维护长期图片路径。

## 后续素材类别

- 职业立绘或角色半身像。
- 敌人立绘。
- 卡牌底框。
- 卡牌插画。
- 地图节点图标。
- 地图背景。
- 战斗背景。
- 法术特效。
- 攻击、受击、破坏等反馈特效。
- UI 图标。

## 待定方向

- 最终视觉风格。
- 卡牌版式模板。
- 敌人表现方式。
- 探索地图视觉形式。

## 素材导入流程

1. 先确认素材用途：UI 贴图、静态场景图、角色精灵、战斗动画、图标或 VFX。
2. 放入 `assets/visual/` 对应分区。
3. 在 `VisualAssetDatabase.gd` 或 `CharacterVisualDatabase.gd` 登记资源 id、路径和占位 fallback。
4. 在 `AssetAttributionDatabase.gd` 登记授权记录。
5. 由 UI、角色视觉 profile 或战斗表现路由引用资源 id，不直接引用裸路径。
