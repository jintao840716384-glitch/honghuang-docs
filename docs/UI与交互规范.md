# UI 与交互规范

## 总体方向

当前 UI 以 Demo 可读性和操作手感为主。界面不追求最终美术，但要保证交互规则明确、反馈统一、不会遮挡核心信息。

## 主流程

- 开始菜单显示开始游戏、设置、离开游戏。
- 设置中当前只提供音效音量。
- 职业选择使用大职业卡展示，点击职业卡选中，再点击确认进入探索。
- 探索地图显示从下往上的节点路线，可用节点高亮，已完成节点变为完成状态。

## 战斗布局

- 玩家位于左侧偏中。
- 敌人位于右侧偏中。
- 法防区在玩家右侧，固定 5 格。
- 装备区在玩家左侧，纵向堆叠。
- 手牌在屏幕底部中央。
- 卡组在右下，墓地和除外区在左下。
- 日志在右侧，以覆盖式面板展开，不挤压主战斗区。

## 手牌交互

- 手牌是完整大卡。
- 鼠标悬停时，只有手牌会上浮、略放大、提高层级。
- 手牌悬停会播放轻微翻卡音效。
- 点击使用后，播放快速上浮淡出残影，表示这张牌已经使用。
- 残影层级高于手牌悬停层，避免被鼠标下方的新手牌遮住。

## 完整大卡规则

完整大卡包括：

- 手牌。
- 选择面板中的卡。
- 奖励面板中的卡。
- 牌堆查看窗口中的卡。

完整大卡已经显示足够信息，因此默认不额外弹出说明框。

除手牌外，完整大卡悬停只保留高亮，不上浮、不放大。

## 缩略卡与悬浮说明

悬浮说明框只用于信息被压缩的卡牌位置：

- 法防区。
- 装备区。

悬浮框固定为短说明框，不应首次显示时被布局拉伸。

## 牌堆查看

- 点击卡组、墓地、除外区会打开模态查看窗口。
- 背景加半透明黑色遮罩。
- 窗口外的战斗 UI 不可操作。
- 点击关闭按钮或窗口外区域都可以关闭。
- 查看窗口中的卡牌不使用手牌上浮动画。

## 法防区与装备区反馈

- 可响应的法防卡会持续呼吸发光。
- 盖伏卡落位、永续法术进入法防区、装备进入装备区时，都播放一次性光晕。
- 装备满时进入替换模式，可替换装备发光，点击后出现确认面板。

## 连锁交互

- 进入响应时，中间显示“连锁”提示。
- 可响应的场上卡在原位置发光。
- 点击可响应卡后出现确认面板。
- 确认后加入连锁。
- 可以跳过响应，结束当前连锁。
