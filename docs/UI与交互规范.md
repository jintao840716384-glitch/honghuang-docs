# UI 与交互规范

## 总体原则

当前 UI 服务 Demo 可读性和操作手感。界面可以是占位美术，但必须让玩家清楚知道：

- 谁能行动。
- 当前能拖到哪里。
- 这次行动会产生什么结果。
- 哪些卡可以发动。
- 当前卡组和备牌区如何变化。

## 主流程界面

- 开始菜单包含开始游戏、设置和离开游戏。
- 设置中当前只有音效音量。
- 角色选择使用角色卡展示；确认角色后进入角色准备界面。
- 角色准备界面左侧展示当前角色、称号、属性、修为点和已开放卡包，右侧提供开始挑战、角色成长、卡包解锁、开局构筑和返回角色选择。
- 角色成长入口位于角色准备界面，显示当前角色可用修为点、累计修为点、称号和可升级项目。
- 角色成长页顶部显示称号、可用 / 累计修为点、当前生命、攻防、基础抽牌和卡组总分上限。
- 成长项按基础属性、卡组与卡包、角色特性、强力规则等分类展示；每项显示当前等级、最大等级、效果说明、下一级消耗和按钮状态。
- 卡包解锁入口位于角色准备界面，显示通用 1-5 和当前角色职业 1-5 的槽位、开放状态、已有卡数、当前识藏等级、下一批卡包和开放成本；修为点足够时可直接提升识藏。
- 开局构筑入口位于角色准备界面，显示当前卡组和备选池两栏；点击当前卡组内的卡会移入备选池，点击备选池的卡会加入当前卡组。
- 备选池只是准备页构筑来源，不等同于探索内备牌区；开始挑战时未选卡不会进入探索备牌。
- 开局构筑必须满足 10-20 张和卡组总分上限后才能开始挑战；编辑过程中允许临时低于 10 张，但开始挑战会阻止非法构筑。
- 探索地图从下往上推进，可用节点高亮，已完成节点显示完成状态。
- 地图左侧显示本轮状态：名称、角色、称号、生命、基础抽牌、灵石、本轮修为、卡组总分和当前加成。
- 地图左侧提供“调整卡组”入口。
- 探索失败和第三层首领胜利后进入探索结算页，展示本轮修为点结算，并提供返回角色界面或再次挑战。

## 角色成长

- 修为点按角色 / 职业分别保存，不在不同角色之间共享。
- 成长面板只显示当前选中角色的升级项。
- 每个升级项显示名称、当前等级 / 最大等级、效果说明、下一级成本和当前是否可买。
- 修为点不足或已满级时按钮禁用。
- 成长项购买后立即刷新角色卡属性、可用修为点和升级列表。
- 境界词在此处作为称号展示，不作为局内每层突破按钮或三选一升级流程。

## 战斗布局

- 我方主单位在左侧，敌方主单位在右侧。
- 每边最多 3 个单位；额外单位在前上 / 前下形成三角阵。
- UI 表达上只有我方阵营和敌方阵营两个牌手；场上单位只是阵营控制的战斗对象，不显示为独立牌手、独立回合或独立卡组。
- 玩家和敌方放置区各 5 格，位于主单位下方横排。
- 敌方手牌、牌库、墓地和除外区不在当前 UI 中显示。
- 手牌在屏幕底部中央。
- 卡组在右下，墓地和除外区在左下。
- 日志是覆盖式面板，不挤压主战斗区。
- 临时测试工具默认折叠，只用于 Demo 调试。

## 单位行动

- 我方阵营回合内，所有尚未使用基础行动额度的我方存活单位卡下方直接显示“攻击 / 防御”按钮。
- 点击攻击后，如果只有一个敌方目标，直接结算。
- 多个敌方目标存在时，进入目标选择。
- 点击防御后，该单位防御力翻倍，持续到下一个玩家回合开始。
- 单位行动后按钮消失。
- 所有我方存活单位都行动过后，“结束回合”按钮发光提示，但不阻止继续使用手牌。

## 目标选择与结果预览

- 平时点击敌方单位只记录目标，不显示持续选中框。
- 进入目标选择时，鼠标悬停敌方单位会显示高亮。
- 点击目标后确认行动。
- 中上方 `ResultPreviewLabel` 显示预计结果。
- 普通攻击预览显示行动单位、目标单位、预计伤害和攻击 / 防御差值。
- 盖伏响应预览显示原始结果，以及发动某张盖伏卡后的结果变化。
- 后续中毒、灼烧、群体效果、状态变化也应扩展到同一块预览区。

## 手牌交互

- 手牌使用完整大卡。
- 只有手牌区卡牌悬停时上浮、略放大并提高层级。
- 选择面板、奖励面板和牌堆查看窗口中的完整大卡只保留高亮，不上浮不放大。
- 无明确场上目标的卡牌通过点击直接发动。
- 有明确目标或投放位置的卡牌可以拖拽。
- 拖拽时合法目标发光。
- 拖到无效区域取消，不消耗卡牌。
- 敌方目标牌可拖到敌方单位。
- 防御牌和永续放置牌可拖到我方放置区空槽。
- 装备牌可拖到我方任意存活单位。
- 旧点击出牌继续保留，拖拽只是补充操作方式。

## 盖伏响应

- 响应时画面中间显示“发动盖伏卡”。
- 说明文案固定为“可发动放置区中发光的盖伏卡”。
- 可发动的盖伏卡在原放置区发光。
- 悬停或点击盖伏卡时更新结果预览。
- 点击可发动盖伏卡后出现确认面板。
- 点击“发动”后，该卡在原位置显示完整卡牌虚影并淡出，然后进入规则结算。
- 点击“结束发动”跳过本次响应。

## 装备区

- 我方主单位装备槽跟随我方主单位左侧纵向排列。
- 非主角我方单位和敌方单位在单位卡旁显示小装备槽。
- 普通单位 1 槽，精英 2 槽，首领 3 槽，我方主单位 2 槽。
- 装备槽只有在装备进场、拖拽投放或替换选择时高亮。
- 空槽不应因普通刷新、攻击或盖伏动作闪光。
- 装备满时进入替换模式，可替换装备发光，确认后旧装备进墓地，新装备进目标单位装备区。

## 牌堆查看

- 点击卡组、墓地、除外区打开模态查看窗口。
- 背景加半透明遮罩。
- 窗口外战斗 UI 不可操作。
- 点击关闭按钮或窗口外区域关闭。
- 查看窗口中的卡牌不使用手牌上浮动画。

## 卡组调整

- 卡组调整只在探索地图中打开。
- 界面分为当前卡组和备牌区。
- 点击当前卡组内的卡，将其移入临时备牌区。
- 点击备牌区内的卡，将其加入临时当前卡组。
- 调整过程中可以临时低于 10 张或清空。
- 点击“保存卡组”时检查 10 到 20 张和卡组总分。
- 点击“退出调整”时，如有未保存改动，提示保存并退出或放弃退出。
- 卡组调整、奖励和坊市卡面底部显示单卡“分数”。
- 战斗手牌不显示分数。

## 探索节点覆盖层

- 事件、宝箱、坊市和休息都使用地图内覆盖层。
- 选项尽量用卡牌式展示。
- 灵石奖励卡中央只显示放大的灵石数字。
- 代价或确认动作放在卡牌下方按钮里。
- 宝箱提供三张卡三选一。
- 坊市显示 6 个商品位，价格放在购买按钮上。
- 坊市出售只面向备牌区。
- 休息当前恢复全部生命。
