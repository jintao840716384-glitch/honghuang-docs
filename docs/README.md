# 太玄宗项目文档索引

本目录只保留当前 Demo 阶段仍有效的规则、交互和开发约定。旧方案、旧文案和早期试错记录不再作为主文档内容保留，避免后续接手时反复辨别哪些已经过期。

## 推荐阅读顺序

1. `太玄宗_卡牌战斗原型_当前状态与交接说明.md`
2. `游戏设计总览.md`
3. `UI与交互规范.md`
4. `当前卡牌清单.md`
5. `数据表与内容配置规划.md`
6. `音频与反馈规范.md`
7. `美术与素材规范.md`
8. `备份与文档维护规范.md`
9. `修改记录.md`

## 文档职责

- `当前状态与交接说明`：给新对话快速接手，记录当前已实现事实、关键代码入口和验证命令。
- `游戏设计总览`：记录当前玩法闭环、战斗边界、探索和卡组模型。
- `UI与交互规范`：记录当前界面布局、拖拽、目标选择、盖伏响应和卡组调整交互。
- `当前卡牌清单`：记录当前通用卡池、职业卡池和初始牌组，方便后续逐张改卡。
- `数据表与内容配置规划`：记录继续扩展卡牌、敌人、敌方卡组和遭遇时应遵守的数据结构。
- `音频与反馈规范`：记录占位音效和反馈节奏。
- `美术与素材规范`：记录当前占位素材边界和后续素材方向。
- `备份与文档维护规范`：记录 GitHub 仓库备份流程、本地压缩包使用边界，以及文档同步规则。
- `修改记录`：只记录从本次清理后的阶段性变化。

## 维护规则

- 影响新对话接手的信息，更新 `当前状态与交接说明`。
- 改变玩法规则，更新 `游戏设计总览`。
- 改变操作方式或界面文案，更新 `UI与交互规范`。
- 改变卡牌内容或初始牌组，更新 `当前卡牌清单`。
- 新增一类可复用数据字段或效果步骤，更新 `数据表与内容配置规划`。
- 小修小补只记到 `修改记录`，不要把历史流水账重新堆回主文档。
- 改变备份、提交、推送或恢复方式，更新 `备份与文档维护规范`。
