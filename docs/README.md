# 太玄宗项目文档索引

本目录用于保存当前 Demo 阶段已经确认的玩法、交互、素材方向和交接信息。现阶段不追求最终工程规格，但要把已经试出来的体验规则及时沉淀，方便后续重构。

## 推荐阅读顺序

1. `游戏设计总览.md`
2. `UI与交互规范.md`
3. `音频与反馈规范.md`
4. `美术与素材规范.md`
5. `数据表与内容配置规划.md`
6. `太玄宗_卡牌战斗原型_当前状态与交接说明.md`
7. `修改记录.md`

## 文档职责

- `游戏设计总览.md`：记录游戏核心方向、回合制战斗、探索地图、职业和基础数值。
- `UI与交互规范.md`：记录界面布局、卡牌交互、弹窗、悬浮、地图节点等操作细节。
- `音频与反馈规范.md`：记录音效触发点、占位音效策略和未来替换方式。
- `美术与素材规范.md`：记录卡牌、角色、地图、特效等美术素材的阶段性要求。
- `数据表与内容配置规划.md`：记录未来卡牌、敌人、事件、奖励等数据表如何拆分。
- `太玄宗_卡牌战斗原型_当前状态与交接说明.md`：给新对话或后续开发快速接手，偏当前实现状态。
- `修改记录.md`：只记录阶段性变化，不写成详细设计文档。

## 维护规则

- 小改动：更新 `修改记录.md`，必要时补一两句到当前状态。
- 系统规则或交互确定下来：同步更新对应设计文档。
- 临时想法但未实现：可以写入对应文档的“待定”部分，不要伪装成已完成。
- 旧方案不要删除，移入 `archive/` 或在文档内标注已废弃。
