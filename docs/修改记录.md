- 职业选择界面改为大职业卡展示，保留剑修、符修两个职业，并通过确认按钮进入探险。

- 战斗场景新增探险模式入口：地图节点进入战斗，胜利后选择奖励，奖励加入本轮卡组，然后返回地图继续选择下一节点。
- 保留原 `BattleUI.setup(job_id)` 和 `BattleManager.start_run(job_id)` 的连续战斗测试模式，避免破坏既有规则检查。
- 新增 `RunFlowSmokeTest.gd`，覆盖菜单、职业选择、地图、探险战斗和奖励返回地图的基础流程。

## 2026-07-05

### 初始战斗原型

- 根据 `太玄宗_卡牌战斗原型执行文档_V0.1.md` 实现可运行 Godot 4 卡牌战斗 Demo。
- 支持职业选择：剑修、符修。
- 支持进入战斗、抽牌、普通攻击、使用法术牌、盖伏防御牌。
- 支持卡组、手牌、墓地、除外区、法防区、装备区。
- 支持战斗胜利后进入下一场，5 场后循环。

### 场景化与模块化重构

- 拆分场景：`Main.tscn`、`JobSelectScene.tscn`、`BattleScene.tscn`、`RewardScene.tscn`、`CardButton.tscn`、`ZoneSlot.tscn`。
- 拆分脚本职责：
  - `BattleManager.gd`：战斗流程。
  - `PlayerState.gd`：玩家战斗状态。
  - `EnemyState.gd`：敌人战斗状态。
  - `DeckManager.gd`：卡组、手牌、墓地、除外区流转。
  - `CardResolver.gd`：卡牌效果结算。
  - `CardDatabase.gd`：卡牌数据。
  - `JobDatabase.gd`：职业数据。
  - `EnemyDatabase.gd`：敌人数据。
  - `BattleUI.gd`：UI 刷新与按钮事件转发。

### 时点与连锁系统

- 增加敌人行动、伤害前、破坏前等响应时点。
- 增加连锁栈。
- 防御牌可加入连锁，按后发先结算。
- 修复防御牌 ready 规则：盖伏当前玩家回合不能发动，但玩家结束回合后即可在敌人回合响应。

### 战斗界面改版

- 从大面板式 UI 调整为战斗场景上叠加 UI。
- 玩家放左侧，敌人放右侧。
- 法防区放在玩家前方。
- 装备区放在玩家附近。
- 手牌放在底部中央。
- 日志改为右侧覆盖式浮层。
- 卡组、墓地、除外区改为小牌堆按钮，点击打开覆盖式查看窗口。

### 手牌 UI

- 手牌改为竖向卡牌。
- 卡名、类型/标签、效果描述分层显示。
- 不再使用普通横向按钮。
- 手牌无数量上限，但展示宽度有限制。
- 手牌过多时自动横向叠放。
- 鼠标悬停时卡牌上浮、放大并提高层级。

### 连锁交互改版

- 移除 `BattleScene` 中旧的大响应弹窗。
- 进入响应时点时，中央显示“连锁”提示。
- 可响应盖伏卡在场上原位置发光。
- 点击可响应卡后出现确认面板。
- 玩家确认后发动；也可以取消选中或结束连锁。

### 装备区与装备替换

- 装备区改为玩家左侧纵向堆叠小卡。
- 场上装备卡颜色改为绿色，与手牌装备卡统一。
- 装备容量从 `PlayerState.equipment_limit` 读取，当前默认 2。
- 装备满时，点击新装备会进入替换模式。
- 可替换装备发光提示。
- 选中旧装备后出现确认面板。
- 确认后旧装备进入墓地，新装备进入装备区。
- 被替换装备会移除自身攻击/防御加成。

### 基础反馈

- 增加普通攻击前冲。
- 增加受击反馈。
- 增加伤害、回复、剑势、减伤、打断等跳字。
- 增加法防区 / 装备区可响应发光。
- 增加装备替换提示。

### 视觉反馈优化

- `ZoneSlot` 发光改为独立底层多层光晕，不再通过调亮卡牌本体表现。
- 可响应盖伏卡、选中响应卡、装备替换候选装备复用同一套持续呼吸光晕。
- 防御牌盖伏落位和防御牌发动 / 连锁结算时，目标槽位播放一次光晕脉冲。
- 使用手牌、盖伏防御牌、确认装备替换时，会从原手牌位置播放上浮、淡出、线框残影的轻量发动动画。
- 动画逻辑集中在 UI 表现层，规则结算仍由 `BattleManager` / `CardResolver` 负责。
- 装备牌进入装备区、永续法术进入法防区时，也会播放同一套一次性光晕脉冲。
- 手牌释放残影层级提高到手牌悬停层之上，并增加上移距离，减少被下一张手牌遮挡的情况。
- 手牌释放残影持续时间缩短，只保留快速的使用提示，减少遮挡视线。

### 牌堆查看交互

- 卡组、墓地、除外区查看窗口改为模态查看。
- 查看窗口打开时，背景覆盖半透明黑色遮罩，外部战斗 UI 不可操作。
- 点击右上角“关闭”或点击窗口外任意位置都会关闭查看窗口。
- 查看窗口内的卡牌悬停时只保留高亮，不再上浮或放大，避免在滚动区域内越界遮挡。
- 选择面板、奖励面板、牌堆查看中的完整大卡不再触发悬浮说明框；悬浮说明框只用于法防区、装备区等缩略卡。

### 占位音效

- `AudioManager` 改为启动时程序生成占位短音效，不依赖外部素材。
- 已接入手牌悬停翻卡声、出牌咻声、盖伏声、永续放置声、装备声、受击声、攻击声、回复声、防御牌发动声、连锁声、胜利声和基础 UI 点击声。
- 敌人破坏法防区卡牌时会触发卡牌破坏音效。
- 当前音效用于验证反馈节奏，未来可通过 `AudioManager.register_stream()` 替换为正式音频素材。
