# 音频与反馈规范

## 当前状态

当前音效全部由程序生成，占位使用，不依赖外部音频素材。音效的目的不是最终品质，而是验证操作节奏和反馈密度。

## 已接入音效

- 手牌悬停翻卡声。
- 出牌声。
- 盖伏声。
- 永续法术放置声。
- 装备声。
- 攻击声。
- 受击声。
- 回复声。
- 防御卡发动声。
- 连锁开始与结算声。
- 胜利声。
- 卡牌破坏声。
- 基础 UI 点击与确认声。

## 音量设置

开始菜单的设置中已有全局音效音量滑条，当前通过 Master 音频总线控制。

## 当前设计原则

- 高频音效要短，避免吵。
- 悬停音效必须有冷却，避免快速移动鼠标时过密。
- 出牌、放置、装备、受击应有明显区别。
- 重大反馈可以更突出，例如胜利、破坏、连锁。

## 未来替换方式

正式音频素材可以通过 `AudioManager.register_stream()` 替换，不需要重写战斗规则。

未来建议拆分音频类别：

- UI 音效。
- 卡牌操作音效。
- 战斗打击音效。
- 法术音效。
- 装备音效。
- 环境氛围。
- 胜利、失败、首领等特殊提示。

## 待定

- 每个职业是否有专属音色。
- 每类卡牌是否有不同施放音。
- 地图界面是否需要环境底噪。
- 首领战是否需要更强音乐层级。
