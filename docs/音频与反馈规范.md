# 音频与反馈规范

## 当前状态

当前音效全部由程序生成，只用于验证操作节奏和反馈密度，不代表最终品质。

## 已接入音效

- 手牌悬停翻卡声。
- 出牌声。
- 盖伏声。
- 永续法术放置声。
- 装备声。
- 攻击声。
- 受击声。
- 回复声。
- 防御卡发动声。
- 盖伏响应开始与结算声。
- 胜利声。
- 卡牌破坏声。
- 基础 UI 点击与确认声。

## 当前原则

- 高频音效要短。
- 悬停音效必须有冷却。
- 出牌、放置、装备、受击要能听出区别。
- 胜利、破坏和盖伏发动可以更突出。

## 后续替换

正式音频素材可以通过 `AudioManager.register_stream()` 替换，不需要重写战斗规则。

未来可拆分：

- UI 音效。
- 卡牌操作音效。
- 战斗打击音效。
- 法术音效。
- 装备音效。
- 地图环境声。
- 首领或章节提示音。
