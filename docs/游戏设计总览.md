# 游戏设计总览

## 当前定位

《太玄宗》当前是修仙题材卡牌战斗 Demo。现阶段重点是验证战斗节奏、职业差异、卡牌流转、探索闭环和内容扩展方式。

暂不做完整商业工程结构，也不急着制作正式美术资源。

## 核心循环

1. 开始游戏。
2. 选择角色。
3. 进入角色准备界面，查看角色成长、卡包解锁和开局构筑。
4. 开始挑战后探索三层主线地图。
5. 进入战斗或处理事件、宝箱、坊市、休息。
6. 战斗胜利后拿奖励卡和灵石。
7. 奖励进入当前卡组或备牌区。
8. 击败第一、二层首领后进入下一层地图，不触发局内境界突破。
9. 击败第三层首领或中途战败后进入探索结算页，展示已完成节点带来的本轮修为点。
10. 回到角色准备界面，消耗当前角色 / 职业的修为点解锁或升级成长项，调整开局构筑，或再次挑战。

## 主线与通关后结构

标准主线固定为三层爬塔。每层是一张包含普通战斗、精英、事件、宝箱、坊市、休息和首领的地图。层与层之间刷新地图并回满生命，但不提供局内境界属性成长。

第四层不作为普通主线层。隐藏 Boss、真 Boss、Boss 连战、完整牌手对手和更高难度挑战都属于通关后系统，后续通过累计修为、境界称号或劫数解锁。

劫数是后续世界难度系统：通关后可逐级解锁，三层结构不变，但敌人基础数值、敌方卡组、Boss 牌包、事件风险和奖励参数会变化。劫数解锁可账号通用，职业局外成长仍按职业分别保存。

## 当前职业

### 剑修

- 生命和攻击偏高。
- 当前初始防御为 0。
- 拥有“剑势”资源。
- 普通攻击命中后获得剑势。
- 剑修牌主要围绕我方主单位普通攻击，而不是独立法术直伤。
- 当前设计方向偏剑势获取、攻击成长、额外攻击、群体攻击、随机多段和下一次攻击倍率。
- 职业牌基本只指向拥有剑修字段的主单位，不优先做防守减伤。

### 符修

- 生命和攻击偏低。
- 当前初始防御为 0。
- 不使用剑势。
- 依靠符牌、检索、回收、复制和防御响应。
- 当前设计方向偏资源流转和效果组合。

当前不新增职业，先把剑修和符修的低分牌、职业核心牌和基础循环做清楚。

## 局外成长与称号

当前不再使用“每打完 Boss 局内突破一次”的成长结构。第一、二层 Boss 胜利只推进下一层地图；第三层 Boss 胜利或中途战败才结算本轮探索，把修为点写入当前角色 / 职业；下一轮开始时读取该角色 / 职业的局外成长。

境界词暂时保留为局外称号：

1. 练气。
2. 筑基。
3. 金丹。
4. 元婴。
5. 化神。
6. 渡劫。

称号根据当前职业累计修为点展示，例如 `筑基剑修`。称号本身暂不附带额外复杂规则，避免和职业成长池重复。

当前修为点规则：

- 每完成一个节点记录本轮基础修为点。
- 普通战斗 3，事件 / 坊市 / 休息 2，宝箱 4，精英 5，首领 10。
- 第三层首领结算或中途战败结算时，按最终到达层倍率写入当前职业。当前三层主线倍率为第一层 x1、第二层 x1.25、第三层 x1.5。
- 战败结算只统计已经完成的节点，正在战败的当前战斗节点不计入本轮基础修为。
- 修为点绑定职业，不跨职业共享。
- 当前职业成长池包含最大生命、攻击、防御、卡组总分上限、基础抽牌、卡池解锁层级和职业特殊项。
- 防御成长较稀有：剑修当前只能升 1 次，符修可升 2 次。
- 成长项 UI 当前按基础属性、卡组与卡包、角色特性和强力规则等分类展示；分类只是显示层级，不改变存档字段或购买规则。

后续抽滤和爆发抽牌优先交给卡牌、职业机制或局外强力成长项，不作为当前默认成长项。

## 卡池解锁

- 奖励、事件、宝箱和坊市不再默认使用完整卡池。
- 卡牌可带 `unlock_tier`、`unlock_pack`、`unlock_packs`、`default_unlocked` 元数据。
- 当前职业成长中的“识藏”会开放下一批编号卡包；保存字段仍兼容旧的 `card_unlock_tier`。
- 角色准备界面的卡包解锁页可直接消耗修为点提升“识藏”，也会展示下一批卡包和当前可用修为点。
- 起始牌组不受卡池解锁过滤影响。
- 当前卡包命名使用编号包，例如 `common_1`、`common_2`、`sword_1`、`sword_2`，避免“基础 / 进阶 / 高阶”暗示强弱。每个编号包都可以包含不同分数段的卡。
- UI 先预留通用 1-5 和当前角色职业 1-5 的槽位，用于后续内容扩充；空槽或少量卡槽不会自动进入奖励池。
- 当前已实现卡牌使用 `CARD_UNLOCK_PACKS` 显式配置包归属；旧 `unlock_tier` / `CARD_UNLOCK_TIERS` 只作为兼容层。
- 默认开放 `common_1` 和当前职业的 `职业_1`；识藏 1 级额外开放第二批，识藏 2 级额外开放第三批。
- 后续可以继续扩展为卡包解锁、指定卡解锁和后期锁卡 / 屏蔽卡机制；当前只做最小层级过滤。
- 遭遇奖励仍按已解锁编号卡包过滤；如果某类遭遇按分数段过滤后少于 3 张候选，会在同一已解锁卡包范围内放宽分数下限，避免 Boss 奖励退化成一选一。

## 卡组模型

- 当前卡组保存范围为 10 到 20 张。
- 每张卡有分数，字段为 `build_cost`。
- 当前卡组的卡组总分不能超过当前职业局外成长后的分数上限。
- 角色准备页可调整本轮开局构筑；当前备选池由职业默认开局牌和已开放编号卡包组成，只作为本轮临时构筑来源。
- 准备页备选池不会作为探索备牌带入本轮；只有被编入当前卡组的卡会随开局进入探索，避免未选卡产生免费出售价值。
- 开局构筑不等于永久收藏系统；当前不保存局外卡牌库存，也不因为该入口引入同名上限。
- 备牌区保存已获得但未编入当前卡组的牌。
- 备牌区不参与战斗，不计入卡组张数和卡组总分。
- 奖励卡优先进入当前卡组；如果张数或分数不允许，则进入备牌区。
- 坊市可出售备牌区卡，当前不直接出售当前卡组内的卡。

当前明确不做：

- 同名卡数量限制。
- 稀有度式卡组限制。
- 额外卡牌数量规则。
- 强制删牌式肉鸽逻辑。
- 五行或属性克制规则。

## 战斗模型

- 战斗抽象上只有我方阵营和敌方阵营两个牌手，按阵营回合推进。
- 每边最多 3 个单位。单位不是独立牌手，也没有自己的卡组或完整回合；单位只是场上的战斗对象，承载生命、攻击、防御、装备、状态、资源和基础行动额度。
- 玩家、敌人、召唤物和未来法宝单位共用 `BattleUnit` 字段。
- 底层数据已拆为角色池、敌方卡组模板和难度曲线：角色池只描述单位是谁；主线层数 + 节点位置 + 战斗类型 + 世界难度先选择敌方卡组模板，卡组模板再引用可出场角色和站位；难度曲线按层数、节点位置、遭遇类型和世界难度追加生命 / 攻击 / 防御。
- 我方侧和敌方侧共用 `BattleSide` 区域模型。
- 敌方后台也有牌库、手牌、墓地、除外区和放置区，只是 UI 暂不展示。
- 我方阵营回合内，每个我方存活单位可执行一次攻击或防御。这是阵营回合中的单位基础行动额度，不是单位自己的回合。
- 防御是通用减伤属性；默认伤害都会被目标防御力减免。
- 只有明确写“无视防御”的卡牌或技能才绕过防御。
- 执行防御时，如果单位当前防御力为 0，则临时获得 1 点防御；如果当前防御力大于 0，则按当前防御力再增加等量防御。
- 敌方阵营回合内，所有敌方存活单位按队列执行基础行动。
- 敌人普通攻击和单体施法会从我方存活单位中选目标。
- 我方主单位死亡时战败；其他我方单位死亡后退场。
- 敌方场上单位全部死亡时战斗胜利。
- 如果同一结算中我方主单位和敌方单位同时死亡，优先判定我方战败。
- 探索状态下生命为 0 时，本轮探索视为失败，不能继续选择地图节点或进入下一场战斗。

## 单位字段与卡牌限制

- 职业本质上是开局选择的默认主单位和卡池解锁来源，不是额外的玩家对象。
- 剑修、符修等职业单位应通过稳定字段识别，例如 `unit_id`、`unit_tags` 或 `job_tags`。
- 玩家自定义名称和 UI 显示名不参与规则判断。
- 职业卡通过字段限制目标或使用者，例如“需要目标拥有剑修字段”。
- 卡牌检索、卡池解锁和卡包筛选只看明确数据字段，例如 `tags`、`search_tags`、`unlock_pack`、`target_requirements`，不要扫描效果说明文本。
- 效果说明只负责展示给玩家阅读；如果后续需要“此牌也视为某某字段”，应增加独立规则字段，不把补丁写进说明文本。

## 卡牌与效果方向

卡牌、敌方技能、首领技能和召唤物行动都应尽量复用效果步骤。

当前已有通用方向：

- 伤害。
- 治疗。
- 攻击 / 防御变化。
- 资源计数器变化。
- 状态计数器变化。
- 召唤。
- 装备。
- 放置区流转。
- 盖伏响应。

新增卡牌时，先判断能否由现有效果组合表达。只有多张卡或多个敌人共同需要新能力时，才补新的通用步骤。

## 探索节点

当前节点类型：

- 普通战斗。
- 精英战斗。
- 首领战斗。
- 事件。
- 宝箱。
- 坊市。
- 休息。

当前奖励分层：

- 普通战斗偏低分基础牌。
- 精英战斗偏中高分核心牌、装备、召唤、盖伏和检索。
- 首领战斗偏高分终端牌或章节奖励。

事件、宝箱、坊市和休息都应使用统一的卡牌式展示，不回退成横条按钮列表。

## 下一阶段重点

1. 继续用真实内容标定三层主线难度、修为点价格和卡包开放节奏。
2. 继续扩充 `common_2 / common_3`、职业 2 / 3 号包和后续 4 / 5 号包候选，保持每包不是单纯强弱阶梯。
3. 按“第几层 + 普通 / 精英 / 首领 + 第几套敌方卡组模板”的粒度继续填充敌方遭遇内容。
4. 扩展敌方牌包，并在敌方放置牌和响应牌接入前先验证主动牌强度。
5. 通过真实内容检验 `EffectResolver`、目标系统和敌方后台牌区还缺什么。

当前测试口径：
- 可见窗口手测不作为固定验收步骤；优先使用无头流程测试和压力探针。
- `SwordThreeLayerRunProbe.gd` 关注无局外成长的三层连续压力。
- `SwordProgressionProbe.gd` 关注不同局外成长和卡包开放阶段的三层连续压力。
- 当前卡池深度仍低于成熟商业卡牌游戏的单职业完整卡池，探针结果只能作为阶段性方向，不应当作最终平衡结论。
