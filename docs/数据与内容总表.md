# 数据与内容总表

本文记录当前活跃内容、字段结构、来源池、数值曲线、资源索引、数据校验口径和待回填数据位。规则权威见 `游戏规则总纲.md`，工程职责见 `实现架构总纲.md`。

本文只保留当前有效数据、字段位置和待回填项。不保留历史修改记录、讨论过程、解释性废话和失败原因。

---

## 1. 文档边界

| 文档 | 职责 |
| --- | --- |
| `游戏规则总纲.md` | 玩法规则、战斗 / 探索 / 结算判定。 |
| `实现架构总纲.md` | 工程目录、模块职责、数据流、规则承载、禁止越权。 |
| `数据与内容总表.md` | 卡牌、卡池、职业、单位、敌方牌包、事件、商店、成长、数值曲线、视觉音频索引。 |

数据表只记录字段、当前内容、数值、索引、启用状态。卡牌描述文本、UI 文案、资源文件名不是规则来源。

## 2. 数据状态标记

| 标记 | 含义 | 是否进入正式入口 |
| --- | --- | --- |
| `active` | 当前活跃内容 | 是 |
| `prototype` | 原型内容，仅开发测试 | 否 |
| `legacy` | 旧内容，仅兼容或能力测试 | 否 |
| `disabled` | 禁用内容 | 否 |
| `pending_fill` | 字段位已定，数据待回填 | 否 |

正式入口包括：初始牌组、奖励、坊市、事件、宝箱、敌方牌包、Boss 奖励、局外成长解锁。

## 5. 卡牌数据

### 5.1 CardDefinition 字段格式

| 字段 | 含义 | 当前要求 |
| --- | --- | --- |
| `card_id` | 卡牌唯一规则 id | 必填，唯一 |
| `name_key` | 卡名本地化 key | 必填 |
| `description_key` | 描述本地化 key | 必填 |
| `card_type` | 法术牌 / 防御牌等基础类型 | 必填 |
| `build_cost` | 构筑分 | 玩家卡牌必填 |
| `tags` | 标签 | 可空 |
| `source_packs` | 来源卡包 | 玩家可获得卡必填 |
| `content_state` | active / prototype / legacy / disabled | 唯一 active 身份源；正式查询只返回 active |
| `target_mode` | 无目标 / 单目标 / 多目标 / 全体 / 随机 / 自身等 | 必填 |
| `target_scope` | 目标范围 | 按需要声明 |
| `activation_area` | 手牌 / 放置区 / 墓地 / 其他 | 未写按类型默认 |
| `activation_timing` | 主动 / 响应 / 强制触发 / 特殊 | 未写按类型默认 |
| `activation_condition` | 发动条件 | 可空 |
| `response_policy` | 是否进入响应链 | 按需要声明 |
| `duration_type` | 一次性 / 永续 / 装备 / 附着 / 复合 | 未写按一次性 |
| `after_use_destination` | 使用后去向 | 未写按规则默认 |
| `effect_steps` | 效果步骤列表 | 必填，可为空效果 |
| `visual_profile_id` | 卡牌视觉 profile | 可空 |
| `audio_profile_id` | 卡牌音频 profile | 可空 |
| `vfx_profile_id` | 卡牌特效 profile | 可空 |

### 5.2 EffectStep 字段格式

| 字段 | 含义 |
| --- | --- |
| `effect_type` | 通用效果类型枚举。 |
| `source_ref` | 来源对象。 |
| `target_mode` | 目标模式。 |
| `target_ref` | 目标引用。 |
| `value` | 数值。 |
| `zone_from` | 来源区域。 |
| `zone_to` | 目标区域。 |
| `filters` | 筛选条件。 |
| `duration` | 持续规则。 |
| `timing` | 触发事件 / 结算时点。 |
| `flags` | 预定义标记。 |

`effect_type` 必须来自稳定枚举。禁止写脚本函数路径、Godot 节点路径或自由文本规则。

## 28. 数据校验清单

启动校验必须覆盖：

```text
Registry 内定义 id / composite key 唯一，content_state 属于合法枚举。
8 张 active card_id 精确；EffectStep.effect_type 来自 EffectResolver 唯一支持集合，target、target_scope、after_use 合法，状态和卡牌引用指向 active 定义。
卡池、职业初始牌组和职业主角色只引用 active 卡牌 / 角色。
敌方牌包 card / character_refs 只引用 active 定义；candidate 标签不决定 active。
三个 active event_id 精确，权重总和 100，option_id 非空且唯一。
成长 composite key 唯一且 active 项引用 active 职业；四个 active status_id 精确。
三条 DifficultyCurve canonical id 精确，normal / elite / boss 各一条，七层数组和标量字段完整并统一引用 active wd0。
地图 layout_id、七排 node type / lane 与宝箱 treasure_id / reward_kind / choice_count 合法；世界难度仅 wd0 active。
CharacterVisualProfile、VisualAsset fallback、BattleAudioRouter 和程序占位音只引用 active canonical id。
六个正式界面、BattleResult error key 和 active 数据 name/description key 存在于唯一 LocalizationDatabase；调用点保留原文 fallback。
缺失视觉 / 音频文件产生 warning；非法 active 身份、字段或悬空引用阻断启动。
```

当前生产启动由唯一 `scripts/data/DataValidator.gd` 消费 `DataRegistry` 索引执行上述校验；卡牌、职业、角色、敌方模板、事件、成长、状态、难度曲线、地图、宝箱、世界难度、视觉、音频和语言定义均以 `content_state` 作为身份字段。缺失但允许 fallback 的视觉/音频资源为 warning，非法 active 数据和悬空引用为阻断错误。
